# Projeto Lista de Contatos
Um projeto que consiste em uma lista de contatos com funcionalidades de CRUD e outros - Solicitado para ser apresentado como nota de AVP1 da disciplina de Desenvolvimento para Dispositivos Móveis.
## Funcionalidades
O app em sí deve desempenhar as seguintes funções:
- Listar os contatos de um usuário;
- Possibilitar o usuário a adcionar novos contatos;
- O usuário poder fazer uma 'ligação simulada' para algum dos seus contatos.
